# 📋 Cadastro de Usuário (Dark/Light Mode)

Interface de cadastro de usuário moderna e responsiva, desenvolvida com foco em design limpo, usabilidade e alternância de temas.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do formulário de acesso.
* **CSS3:** Estilização avançada, efeitos de transparência (Glassmorphism) e suporte a modo escuro/claro.
* **JavaScript:** Lógica interativa para o botão de alternância de tema (Dark Mode).
* **Git e GitHub:** Versionamento e deploy automatizado.

---

## 🚀 Acesse o Projeto

Você pode testar a interface em funcionamento clicando no link abaixo:

👉 **[Ver Cadastro de Usuário Online](https://th3marcos.github.io/desafiocadastro/)**

---

## 📌 Funcionalidades

* **Design Moderno:** Card centralizado com efeito translúcido sobre imagem de fundo imersiva.
* **Alternância de Tema (Dark Mode):** Botão dedicado para transição de cores da interface.
* **Formulário Prático:** Campos essenciais para Nome, E-mail e Senha.
